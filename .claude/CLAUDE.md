## Project Overview

TempTalk iOS is an enterprise office IM app for private company communication with:
- End-to-end encryption via Signal Protocol
- Real-time chat, voice/video calls (WebRTC/LiveKit)
- Group communication for enterprise use

### Module Structure

```
TempTalk/src/            // Main app (ViewControllers, AppDelegate, Jobs, NewCall)
TTServiceKit/src/        // Core business logic (Account, Contacts, Messages, Storage)
TTMessaging/             // Messaging UI framework (Theme, ViewControllers)
TTShareExtension/        // Share extension
NSE/                     // Notification Service Extension
Modules/                 // Custom modules (FTS5SimpleTokenizer)
DTProto/                 // Protocol buffers FFI library
```

### Key Technologies

| Category | Technologies |
|----------|-------------|
| **Core Stack** | Swift 5.9, Objective-C, UIKit (SwiftUI for call views) |
| **Network** | AFNetworking, SocketRocket (WebSocket), SwiftProtobuf |
| **Database** | GRDB.swift + SQLCipher (encrypted) |
| **Security** | Signal Protocol (SignalCoreKit, Curve25519Kit) |
| **Media** | WebRTC, LiveKit |
